# NAVRYA Static Page Notes

The character and selection pages are responsive standalone previews. Open their `index.html` files
directly for local visual inspection. These notes do not define the production runtime: use
`ARCHITECTURE.md` and the source code for that contract.

The character previews share multilingual UI support for `fa`, `ar`, `en`, and `es`, local market
clocks, rotating slogans, and a demonstration AI conversation. Each page retains its own theme and
assets. Per-page README files record only those page-specific differences.
