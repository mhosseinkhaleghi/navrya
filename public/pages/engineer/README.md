# Engineer's Chart Journal

یک پیاده‌سازی استاتیک و واکنش‌گرا از داشبورد «مهندس بازار» است. برای دیدن آن، فایل `index.html` را در مرورگر باز کنید.

تصاویر اختصاصی تم مهندسی در `assets/` نگهداری می‌شوند. زبان‌های فارسی، عربی، انگلیسی و اسپانیایی، ساعت‌های محلی، شعارهای چرخشی و گفت‌وگوی نمایشی AI همگی در فرانت‌اند آماده‌اند.
