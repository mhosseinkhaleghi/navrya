# NAVRYA Agent Skills

Read `AGENTS.md` and `HANDOFF.md` before every task. Then read the skills that match the task:

| Task | Required skills |
| --- | --- |
| Any code change | `navrya-git-collaboration`, `navrya-architecture`, `navrya-javascript-engineering` |
| Branch sync, commit, rebase, or promotion | `navrya-git-collaboration` |
| Staging or production release, server, Docker, DNS, Caddy, or Actions work | `navrya-git-collaboration`, `navrya-deployment` |
| UI, branding, character dashboard, React view, or i18n work | `navrya-architecture`, `navrya-javascript-engineering`, then the applicable `public/pages/shared/navrya/components/**/*.prompt.md` files |
| AI, Copilot, or Voice work | `navrya-architecture`, `navrya-javascript-engineering`, then the relevant `docs/ai/*.md` file |

The skills are concise operating instructions. The linked source documents and the implementation/tests are the detailed reference and final authority.
